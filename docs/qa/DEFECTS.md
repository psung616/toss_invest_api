## DEF-001 — 연결 테스트 실패 후에도 "완료" 표시
- **등급**: S2 (사용자를 오도: 키가 없는데 사용 가능하다고 안내)
- **재현**: `tossinvest-mcp.exe` 더블클릭 → Client ID·Secret 비워 둔 채 [저장하고 연결 테스트]
- **기대**: "키를 입력하세요" 류 안내 후 중단. Claude Code 등록·"완료!" 문구 없음
- **실제**:
  ```
  연결 테스트 중...
  ✖ 저장된 키가 없습니다.
  Claude Code 에 등록 중...
  ✔ Claude Code 에 'tossinvest' 로 등록했습니다.
  완료! Claude 에서 "삼성전자 현재가 알려줘" 라고 물어보세요.
  ```
- **원인(분석)**: `cli/SetupWindow.java` `runSetup()` 에서 `steps.testConnection()` 결과를 출력만 하고 `ok()` 를 확인하지 않은 채
  등록 단계로 진행(약 147행). 빈 입력이면 저장 단계도 건너뛰는 것으로 보임 → 빈 입력 검증 부재.
- **부수 영향**: 키 없이 Claude Code 에 `tossinvest` 가 등록됨 → 도구 호출 시마다 키 없음 오류. 콘솔 `setup`(ConsoleSetup) 도 같은 흐름인지 확인 필요.
- **수정 방향(제안)**: 빈 입력 즉시 거부, 연결 테스트 실패 시 등록·완료 문구 생략하고 실패 안내로 종료. 회귀 테스트로 흐름 고정.
- **수정 (2026-11-25)**: 단계 순서를 `cli/SetupFlow` 한 곳으로 모으고 콘솔·창이 공유. 한쪽만 입력·공백 입력·키 없음은 연결 테스트 전에 거부,
  저장/연결/등록 중 하나라도 실패하면 이후 단계 생략 + "완료" 미표시, 등록 여부 질문은 연결 성공 뒤에만. 콘솔 setup 은 실패 시 종료 코드 1.
  회귀 테스트 `SetupFlowTest` 10개.
